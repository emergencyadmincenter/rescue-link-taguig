# Web

Next.js frontend for Rescue Link Taguig.

## Development

```bash
npm install
npm run dev
```

## Scripts

- `npm run dev` - start the local development server
- `npm run build` - build the production app
- `npm run start` - run the compiled app
- `npm run lint` - run ESLint
- `npm run test` - run unit tests
- `npm run test:ci` - run tests in CI mode

## Structure

- `src/app/` - App Router pages and layouts
- `src/components/` - shared UI and component building blocks
- `src/features/` - feature-specific code
- `src/design-system/` - tokens, foundations, and theme styles

## Notes

- `next-env.d.ts` is generated by Next.js and is intentionally ignored in the package-level `.gitignore`.
- Keep frontend secrets in local `.env.local` files only.
